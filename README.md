# Laravel Notification Preferences

## Laravel Boost

This package ships Boost AI guidelines in `resources/boost/guidelines/core.blade.php`. They are installed automatically when an application runs `php artisan boost:install`.

## Development

```bash
composer install
composer test
composer lint
composer format
```
